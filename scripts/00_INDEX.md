## 🛠 GLOBAL TECHNICAL STACK (Reference)

All experiences share a foundation:

```
Core Framework:    React Three Fiber (R3F) + Drei
3D Engine:         Three.js r158+
Animation:         GSAP ScrollTrigger + Leva
Shaders:           Custom GLSL (vertex + fragment)
Physics:           Rapier (where needed)
Post-processing:   @react-three/postprocessing
Audio:             Howler.js / Tone.js
Performance:       R3F Offscreen Canvas + Suspense + LOD
Build:             Vite + TypeScript
```
