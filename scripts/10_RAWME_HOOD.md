## STEP 1: DEEP RESEARCH — ACTIONABLE INSIGHTS

### Identity Analysis and Positioning

Rawme Hood — the name itself is a cipher. **Robin Hood** meets **Raw** — the storytelling archetype of someone who takes from the overproduced, oversanitized mainstream and gives raw truth back to the underground. Whether Rawme Hood is a gamer, rapper, content creator, or hybrid creator, the name tells the brand story completely: **rebel redistributor of authentic culture**.

This analysis builds the brand from its name-philosophy outward, as the name is the most important brand signal:

- **"Raw":** Unfiltered, unproduced, authentic first-take energy. The anti-polish brand position.
- **"Me":** Hyper-personal. First-person confession culture. "This is me, exactly as I am."
- **"Hood":** Street origins. Community protection. The hood takes care of its own. Underground loyalty.
- **"Robin Hood" composite:** Takes the tools of the elite (platform reach, production, distribution) and redirects the power to people who deserve it but don't have access.

### Cultural Positioning Built from the Name
- Anti-mainstream: the creator who says what others won't
- Community-protective: builds a tight inner circle that feels exclusive but is open to the real ones
- Raw aesthetic: intentionally lo-fi in a hi-fi world — a political choice, not a limitation
- Underground credibility: the audience who found Rawme Hood before he blows feel ownership of the discovery

### Emotional Triggers
- **Discovery:** The feeling of finding something real before everyone else
- **Loyalty:** Rawme Hood's audience feels chosen, not just subscribed
- **Authenticity:** In a world of brand-managed personas, raw truth feels revolutionary
- **Rebellion:** Against the polished, the corporate, the calculated

### Visual Identity (Derived from Brand Philosophy)
- Glitch aesthetics: VHS distortion, broadcast signal errors, CRT static
- Dark underground environments: basement studios, back alleys, neon-lit corridors
- Green/amber on black: surveillance camera palettes, night-vision, underground bunker
- Typography: broken, distorted, stencil, ransom-note energy
- Analog textures: VHS, Super 8, lo-fi grain — raw as a deliberate choice

### Core Narrative Archetype
**The Raw Rebel / Signal in the Noise** — In a world of perfectly curated content, Rawme Hood is the signal that breaks through the interference. The underground transmission that the mainstream can't silence.

## STEP 2: EXPERIENCE STRATEGY

### Concept: "The Pirate Broadcast"

The user discovers an unauthorized broadcast signal — Rawme Hood has hacked into the mainstream channel and is broadcasting FROM the underground. The experience is styled as if the user accidentally tuned into a pirate radio station (but 3D). Each scene is a different "frequency" — a different dimension of the rawme world. **You're not visiting a website. You're receiving a transmission.**

Why this works:
- The pirate broadcast framing is completely original in the brand website space.
- It justifies the lo-fi aesthetic as a feature, not a bug — pirates use the equipment they have.
- Every piece of "glitch" or "error" in the design is now intentional storytelling, not a mistake.
- The audience that finds this brand will feel exactly what the brand wants them to feel: "I discovered something the mainstream doesn't know about."
- The framing creates urgency: this signal might get shut down. Stay tuned.

### SCENE 1 — "SIGNAL ACQUIRED: BREAKING THROUGH THE STATIC"
**Scroll Range:** 0–12%

**Environment:**
Static. Overwhelming TV static in 3D space. Not 2D — actual 3D noise particles filling the entire viewport. The static is a WALL the user must push through. It's aggressive and immediate. Then: a frequency emerges. A single clear channel breaks through the noise. **The signal finds you.**

**Camera Choreography:**
- Start: inside the static — camera is everywhere and nowhere
- Static has depth: particles at different Z-distances create 3D snowstorm
- As scroll progresses: particles begin to part — a corridor opens
- Camera follows the corridor: tight, claustrophobic, urgent
- At end of corridor: first glimpse of the underground space

**Object/Character Animation:**
- Static particles: 2M points, random positions, constantly relocating (noise function)
- Corridor formation: particles respond to scroll — move aside like parting curtains
- Emerging signal: a single green waveform appears, stable among the chaos
- At 10%: "SIGNAL ACQUIRED" text in 8-bit font materializes

**Transition:**
Signal acquired → static collapses inward → reveals underground studio → Scene 2

**Visual Effects:**
- Static: custom GLSL noise shader + particle system hybrid
- Corridor: particles use scroll-driven repulsion field (SDF corridor)
- Waveform: sine/square/triangle animated wave geometry
- Text: CRT display shader (scanlines + flicker + phosphor glow)

**Interaction Details:**
- Mouse movement: creates temporary clear zones in the static
- Fast scroll: corridor opens violently — particles blast apart
- Slow scroll: static clears gradually, mysteriously
- Hovering: cursor becomes a "signal receiver" (visual indicator)

**Sound Design:**
- TV static white noise: LOUD immediately
- Then: a voice breaking through — distorted, barely intelligible
- Voice says: "You found it. Good."
- Signal tone: 440Hz sine (the broadcast test signal)

### SCENE 2 — "THE BASEMENT STUDIO: SOURCE POINT"
**Scroll Range:** 12–27%

**Environment:**
An underground basement studio. But not the aesthetic-basement of YouTube — the REAL kind: exposed pipes, concrete walls, foam-mattress acoustic panels hanging by duct tape, old CRT monitor, tangle of wires. A mixing board that's seen better days. This is where the signal originates. **Not despite the conditions — because of them.**

**Camera Choreography:**
- Emerges from above: camera descends through the floor from Scene 1
- Low ceiling: camera stays below 1.6m (cramped, intimate)
- Slow orbit around the mixing board — 180° over 5 scroll-seconds
- Arrives at the monitor: extreme close-up on the CRT screen

**Object/Character Animation:**
- Equipment: all analog — nothing digital visible
- Mixing board faders: moving on their own (the session is active)
- CRT monitor: showing what appears to be a live stream, but it's the user themselves (mirror effect)
- Wires: slight sway — vibration from the bass frequency in the room
- Foam panels: micro-breath motion (the room is alive)

**Transition:**
CRT monitor shows signal spreading → waves expand from studio → Scene 3

**Visual Effects:**
- Basement: extreme AO (dark corners, deep shadows)
- CRT screen: custom shader (phosphor glow + scanline + curvature + flicker)
- Fader movement: sine-wave driven, reactive to audio frequency
- Wire physics: Verlet chain simulation

**Interaction Details:**
- Click any fader: it changes audio EQ (actual audio effect on any playing music)
- Hover CRT screen: the mirror effect zooms in — user sees themselves (front camera if available)
- The mixing board is a playable EQ — first fully interactive object in the experience

**Sound Design:**
- Low-frequency rumble: felt not heard
- Mixing board knob static and crackle
- The music being made: a lo-fi beat, just the foundation layers
- Expanding with each scroll section

## STEP 4: ADVANCED EXPERIENCE DETAILS

### Scroll Speed Dynamics
| Speed | Effect |
|---|---|
| Very slow | Static parts slowly — the signal struggles through (tense) |
| Normal | Pirate broadcast pacing — urgent but decipherable |
| Fast | Glitch intensifies — the fast scroll itself creates noise artifacts |
| Very fast | Emergency broadcast mode — red tinted, everything distorts |

### Slow Motion Moments
- Static parting (Scene 1): 0.4x — the emergence must be earned
- Community acknowledgment (Scene 4): real-time (0.5x) — each face deserves a moment
- Broadcast interruption (Scene 5): 0.3x — the interruption is the point

### Dramatic Pauses
- "You found it. Good." (Scene 1): 2s complete stillness — the hook sets
- Community beacon launch (Scene 4): 1.5s silence before blast
- Scene 6 (direct address): THE WHOLE SCENE IS A PAUSE — intentional stillness

### Key Wow Moments
1. **Static wall + corridor opening** — unlike any website opening ever seen
2. **Mixing board as playable EQ** — clients gasp at interactive sound design
3. **Front camera mirror on CRT** — meta moment that breaks the fourth wall
4. **User voice recording → distorted broadcast** — they become part of the brand story

## STEP 5: TECHNICAL TRANSLATION

### Stack
```
Framework:    React Three Fiber + Drei
Particles:    Custom GPGPU for 2M static particles
Audio:        Web Audio API (full control — mixing, distortion, EQ)
Camera:       MediaDevices API (front camera for CRT mirror)
Recording:    MediaRecorder API (voice capture Scene 6)
Glitch:       Custom GLSL shader library
```

### Key Techniques

**Static Particle Field (Scene 1):**
```javascript
// GPGPU-based position randomization
// Each particle jumps to new random position each frame
// Corridor: SDF defines empty cylinder in particle space
const corridor = (pos, scrollProgress) => {
  const radius = (1.0 - scrollProgress) * 5.0;
  return length(pos.xz) > radius ? pos : randomize(pos); // outside corridor = static
};
```

**CRT Shader (Scene 2):**
```glsl
// Full CRT simulation
vec2 curve = vUv * 2.0 - 1.0;
curve *= 1.0 + vec2(curve.y * curve.y, curve.x * curve.x) * 0.08; // curvature
vec2 curvedUv = (curve + 1.0) / 2.0;
// Scanlines
float line = step(0.5, fract(curvedUv.y * uResolution.y * 0.5));
// Phosphor glow
vec3 phosphor = texture2D(map, curvedUv).rgb * vec3(1.0, 0.9, 0.8);
// Chromatic aberration
float r = texture2D(map, curvedUv + vec2(0.002, 0)).r;
float b = texture2D(map, curvedUv - vec2(0.002, 0)).b;
gl_FragColor = vec4(r, phosphor.g, b, 1.0) * (0.85 + line * 0.15);
```

**Front Camera Mirror (Scene 2):**
```javascript
// Request front camera access
const stream = await navigator.mediaDevices.getUserMedia({
  video: { facingMode: 'user' }
});
const video = document.createElement('video');
video.srcObject = stream;
const texture = new THREE.VideoTexture(video);
crtMaterial.map = texture;
// Add CRT shader on top
```

**Voice Recording + Distortion (Scene 6):**
```javascript
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
const recorder = new MediaRecorder(stream);
const chunks = [];
recorder.ondataavailable = (e) => chunks.push(e.data);
recorder.onstop = () => {
  const blob = new Blob(chunks);
  const audio = new Audio(URL.createObjectURL(blob));
  // Apply Web Audio distortion chain
  const distortion = audioContext.createWaveShaper();
  distortion.curve = makeDistortionCurve(400); // heavy distortion
  audio.connect(distortion).connect(audioContext.destination);
};
```

**Glitch Shader (Scene 5 broadcast interruption):**
```glsl
float glitchTime = mod(uTime, 3.0); // glitch cycle
float glitch = step(0.9, sin(glitchTime * 10.0 + vUv.y * 20.0));
vec2 offset = vec2(glitch * 0.05, 0.0);
vec4 color = texture2D(map, vUv + offset);
float scanBar = step(0.98, fract(vUv.y + uTime * 2.0));
gl_FragColor = mix(color, vec4(0.0, 1.0, 0.2, 1.0), scanBar * glitch);
```
